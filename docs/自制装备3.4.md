| 10次 | 4 | 4 | 3 | 2 | 1 |

## 五、洗练与升级机制

词条可升级上限随洗练次数提升，**每10次洗练增加1级升级上限，最多6级（需要洗练50次）**，每次洗练消耗1元晶提升位置0精炼时的固定属性1点（第一条属性）。

**各部位固定属性（0精炼时第一条）：**

| 部位 | 固定属性 |
|:----:|:--------:|
| 武器 | 攻击 |
| 暗器 | 攻击 |
| 戒指 | 命中 |
| 项链 | 躲闪 |
| 护腕 | 招架 |
| 其余部位 | 防御 |

洗练次数达到**25次**之后可添加**特殊能力**，数量固定为1，不可升级。

### 升级词条界面

```
╔══════════════════════════════════════════════════════════════╗
║                                                              ║
║  是否确认提升词条为[臂力：+32]？需要一块[后天属性：臂力]     ║
║                                                              ║
║     ┌──────────┐                                            ║
║     │确定提升(橙)│                                           ║
║     └──────────┘                                            ║
║                                                              ║
╚══════════════════════════════════════════════════════════════╝
```
提升消耗的词条数量不同，初始添加词条后为1级，后续升级均为对应目标等级数量的对应词条

### 替换词条界面

词条的升级需要消耗对应属性材料，消耗的材料数量随词条等级提升。**替换词条会消耗黄金并返回全部消耗的材料，分解会损失1元晶。**

## 六、能力词条装备位置

不同技能类型能力词条可装备位置固定：

| 技能强化类型 | 可装备位置 |
|:-----------:|:---------:|
| 武器强化 | 武器 |
| 拳脚强化 | 武器 |
| 暗器强化 | 暗器 |
| 内功强化 | 衣服 |
| 招架强化 | 护腕 |
| 轻功强化 | 鞋 |

> 双位置技能，所有强化按照**第一个位置**装备。
> 例如：衡山五神剑"每次装备为招架时可设置五神赋召唤目标"强化是招架技能强化，可装备位置按照第一位置武器算，需装备武器位置。
