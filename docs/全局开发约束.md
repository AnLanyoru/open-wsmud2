
### 类型标注准则

> **编写代码时，必须遵循以下类型标注规则：**

1. **对象类型属性必须显式标注类型。** 当类属性值为对象字面量（`{...}`）时，必须标注类型：
   ```typescript
   // ✅ 正确
   prop: PropMap = { gj: 10, fy: 5 };
   condition: LearnCondition = {
       skill: { sword: 100 },
       str: 30,
   } ;

   // ❌ 错误：缺少类型标注或未使用具体类型标注而使用 as Record<string, ...>
   prop = { gj: 10, fy: 5 };
   prop = { gj: 10, fy: 5 } as Record<string, unknown>;
   ```
   如果没有现成类型可以使用，询问开发者来创建新的类型
