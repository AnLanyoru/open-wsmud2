# 四方试炼与武道塔主需求

## 1. 文档目的

本文档定义武道塔顶部“四方试炼”、四神兽 NPC 以及“武道塔主”的功能需求。

本次范围包括：

- 补全青龙、白虎、玄武、朱雀四神兽试炼。
- 定义试炼心跳、层数、失败和清理机制。
- 在武道塔顶部增加“武道塔主” NPC。
- 增加四方试炼规则说明和自制武器词条材料兑换入口。

## 2. 名词与时间口径

### 2.1 息

- 一息等于一次服务器心跳。
- 当前配置下一次心跳为 5 秒，因此一息等于 5 秒。
- 试炼层数使用整数 `n` 表示，玩家显示状态为“`n息`”。
- `n息` 是一个会被替换的独立状态，不是同名状态叠层；客户端不应显示为“息 × n”。

### 2.2 心跳顺序

试炼房间负责统一驱动心跳，每次有效心跳按以下顺序执行：

1. 若玩家已存在息数状态，检查玩家在上一息区间是否完成当前试炼的生存条件；不存在息数状态时跳过该检查。
2. 若必需标记不存在，立即调用玩家正常 `die()` 流程结束试炼。
3. 删除本轮检查过的临时标记，防止标记跨息沿用。
4. 息数 `n` 增加 1。
5. 用新息数替换玩家身上的试炼状态。
6. 按新息数重新设定当前神兽的试炼数值。

首次心跳时玩家还没有息数状态，因此不检查招架、躲闪、命中或造成伤害标记，仅将玩家设为 `1息`，给予完整的第一息操作窗口。后续每次心跳先检查上一息标记，再使用覆盖/替换方式改为下一息。

## 3. 通用试炼规则

### 3.1 进入与对局隔离

- 玩家到达武道塔顶后，可分别进入青龙台、白虎台、玄武台和朱雀台。
- 试炼房间保持单人影子房机制，不允许其他玩家或跟随物影响当前试炼。
- 进入时为玩家生成且仅生成一只对应神兽，随后神兽主动与玩家进入生死战。
- 试炼房间禁止原地复活。

### 3.2 神兽通用属性

- 四神兽的最大气血和当前气血均为 `100,000,000`。
- 神兽在试炼期间不会死亡。
- 神兽气血降至 0 或以下时，不进入普通 NPC `die()` 流程，而是立即恢复至 `100,000,000`。
- 回满不代表试炼胜利，也不掉落物品、不产生尸体、不中断当前战斗。
- 神兽免疫所有标记为 `downside` 的负面状态，包括忙乱、昏迷、属性减益和持续性伤害状态。
- 神兽的试炼属性不通过普通面板无限增长；特殊判定应放在对应的专用技能钩子中，以避免过高面板和过大随机性。
- 白虎、青龙和玄武的攻击、命中、招架、躲闪、防御五项基础面板均固定为 `100,000`。
- 朱雀的命中、招架、躲闪、防御四项基础面板均固定为 `100,000`；仅攻击与破防按试炼息数成长。

### 3.3 玩家试炼状态

进入试炼后，玩家会获得一个绿色正面显示状态。第 `n` 息时：

- 状态名称：`n息`。
- 状态持续时间：5 秒。
- 绝招冷却/释放时间增加 `n%`。
- 疗伤效果降低 `n%`。
- 属性通道使用 `releasetime_per: -n` 与 `recover_per: -n`。
- 状态不设置叠层次数；每息完整替换旧状态，使名称、描述、属性和剩余时间一致。

### 3.4 试炼失败与清理

以下任一情况结束当前试炼：

- 白虎、青龙或玄武试炼在心跳检查时缺少对应的本息成功标记。
- 朱雀试炼中玩家被击杀。
- 其他试炼中玩家因神兽或其他战斗伤害被击杀。
- 玩家主动离开、掉线超时或通过其他途径离开试炼房间。

结束时必须统一执行：

- 删除玩家的试炼息数状态。
- 删除本息成功标记、试炼类型、开始时间等临时数据。
- 停止玩家与神兽的战斗。
- 销毁神兽，防止影子房间残留活跃 NPC。
- 恢复玩家被试炼临时替换的生命周期回调。

## 4. 四神兽试炼

所有数值均按当前息数 `n` 动态计算。已给定的 49 息数值是精确锚点；中间息数默认按线性增长处理。

### 4.1 白虎：招架/躲闪试炼

#### 目标

玩家必须在相邻两次心跳之间，至少成功招架或躲闪白虎的一次攻击。

#### 标记

- 玩家成功招架或躲闪白虎攻击时，为玩家写入“本息防守成功”标记。
- 下一次心跳检查该标记。若不存在，立即调用玩家 `die()`。
- 成功检查后删除标记，开始下一息统计。

#### 特殊命中判定

- 白虎自身的面板命中 `mz` 不随息数增加。
- 白虎使用专用攻击技能，在技能命中钩子中依次进行特殊躲闪和招架判定：先判定躲闪，躲闪失败后再判定招架。
- 躲闪与招架分别使用玩家对应属性与当息阈值比较，任意一项成功即视为本次攻击防守成功。
- 特殊判定应以阈值为主，避免普通命中公式带来的过大随机性。
- 49 息时，玩家需要 `420,000` 躲闪或招架才能通过特殊判定。
- 默认线性阈值：`ceil(420000 * n / 49)`。

### 4.2 朱雀：防御试炼

#### 目标

玩家承受朱雀逐息增强的六连击，存活时间越长，试炼成绩越高。

#### 攻击规则

- 朱雀每息执行一段六连击。
- 朱雀的忽视防御随息数增加，使用 `diff_fy_per2`，不经过普通百分比破防的高值收敛。
- 49 息时 `diff_fy_per2 = 98`，默认线性公式为 `2 * n`。
- 49 息时，单次六连击的总伤害基准为 `50,000,000`。
- `50,000,000` 为进入玩家防御、免伤及其他受伤计算前的基准总伤害，不是玩家最终实际承受伤害。
- 默认线性总伤害基准：`floor(50000000 * n / 49)`。
- 总伤害分配到 6 段，取整余数并入最后一段，确保 6 段基准值之和等于当息总伤害基准。
- 玩家在任意一段伤害中死亡时，立即进入正常 `die()` 流程并结束试炼。
- 朱雀试炼不使用“本息成功”标记，也不因缺少标记而秒杀玩家。

### 4.3 青龙：命中试炼

#### 目标

玩家必须在相邻两次心跳之间，至少命中青龙一次。

#### 标记

- 玩家的攻击必须经过标准 `do_attack()` 流程并命中青龙，才为玩家写入“本息命中成功”标记。
- 下一次心跳检查该标记。若不存在，立即调用玩家 `die()`。
- 命中仅要求该次 `do_attack()` 未被躲闪且未被招架，不要求最终伤害大于 0。
- 反震、持续伤害、绕过 `do_attack()` 的直接扣血、装备附加伤害以及跟随物的攻击均不能为玩家写入青龙成功标记。

#### 特殊躲闪/招架判定

- 青龙自身的普通躲闪 `ds` 和招架 `zj` 不随息数无限增加。
- 青龙使用专用轻功与招架技能，在对应钩子中根据玩家命中值进行阈值判定，以降低随机性。
- 49 息时，玩家需要 `490,000` 命中才能命中青龙。
- 默认线性阈值：`10000 * n`。

### 4.4 玄武：攻击试炼

#### 目标

玩家必须在相邻两次心跳之间，至少对玄武造成一次大于 0 的最终伤害。

#### 固定免伤与标记

- 玄武使用固定值伤害减免 `diff_sh`，该数值每息增加。
- 49 息时 `diff_sh = 4,900,000`。
- 默认线性公式：`100000 * n`。
- 仅当单次攻击通过全部防御与免伤计算后，对玄武造成的最终伤害大于 0 时，为玩家写入“本息攻击成功”标记。
- 下一次心跳检查该标记。若不存在，立即调用玩家 `die()`。

玄武的失败条件为“一息内未对玄武造成实际伤害”；原始需求中“无法招架”为笔误。

## 6. 成绩与世界纪录

- 四种试炼分别使用现有世界数据键 `wd_ss0` 至 `wd_ss3`。
- 索引映射为：`0 = 青龙`、`1 = 白虎`、`2 = 玄武`、`3 = 朱雀`。
- 玩家结束试炼时，将完成的整息数作为成绩。
- 当成绩高于当前世界纪录时，更新 `wd_ss{type}` 和纪录保持者 `wd_ss{type}_n`。
- 记录保持者使用玩家当前名称。
- 塔区界面对已解锁玩家始终显示四方试炼入口；没有世界纪录时显示“暂无纪录”，不得隐藏入口。
- 试炼成绩按息数计算，息数越高越好。

### 6.1 个人首次到达奖励

- 每种试炼分别记录玩家个人曾经到达的最高息数。
- 玩家在某种试炼中首次到达第 `n` 息时，立即获得该试炼对应的自制基础属性石 1 块。
- 首次心跳将玩家设为 `1息` 时，立即发放第 1 息奖励；后续每首次到达一个新息数时同样立即发放。
- 同一神兽的同一息数奖励每个玩家只能获得一次；重复挑战未超过个人最高息数时不重复发放。
- 奖励映射为：

| 神兽 | 试炼 | 奖励 | 物品路径 |
| --- | --- | --- | --- |
| 玄武 | 攻击试炼 | 防御基础属性石 | `st/p#fy` |
| 朱雀 | 防御试炼 | 攻击基础属性石 | `st/p#gj` |
| 青龙 | 命中试炼 | 躲闪基础属性石 | `st/p#ds` |
| 白虎 | 招架/躲闪试炼 | 命中基础属性石 | `st/p#mz` |

- 个人奖励进度必须永久持久化，不随下线、服务器重启或日/周期切换重置。
- 息数状态、个人记录更新和物品发放应在同一次心跳内完成，并防止并发或重入导致重复奖励。

## 7. 武道塔主

### 7.1 NPC 定义

- 位置：武道塔顶 `wudao/ding`。
- 名称：武道塔主。
- 最大气血和当前气血：`56,000,000`。
- 武道塔主不可被攻击，不进入战斗。
- 塔主为可对话 NPC，至少提供“四方试炼”和“词条兑换”两个询问选项。

### 7.2 询问：四方试炼

塔主应向玩家说明：

- 一息等于 5 秒。
- 试炼每息都会增强，并增加玩家绝招冷却、降低疗伤效果。
- 白虎考验招架与躲闪，每息至少成功防守一次。
- 朱雀考验防御与生存，定期使用破防逐步增加的六连击。
- 青龙考验命中，每息至少命中一次。
- 玄武考验单次攻击能力，每息至少突破固定免伤一次。
- 无法完成当息条件或被神兽击杀都会结束试炼。

说明文案应以玩家可理解的玩法表述为主，不直接暴露临时标记、技能钩子和属性键等实现细节。

### 7.3 询问：词条兑换

词条兑换对象指现有自制装备属性材料 `st/p#属性键`，不直接拆除或改写玩家已装配在自制武器上的词条。材料等级按现有词条评分类别从低到高划分：

`base 基础属性 → acquired 后天属性 → advanced 高级属性 → rare 稀有属性 → special 特殊属性`。

交互形式为塔顶房间物品操作：

- 玩家通过塔主的“词条兑换”询问进入兑换操作。
- 玩家可将同一种低等级词条材料 2 块合成 1 块下一等级词条材料。
- 玩家可将一块最高等级 `special` 词条材料无损兑换为 16 块玩家选定的最低等级 `base` 词条材料。
- `special → base` 兑换消耗 100 两黄金，对应现有金钱数值 `1,000,000`；其他 2:1 向上兑换全部免费。
- 所有兑换必须在扣除前显示输入、输出和费用，经玩家二次确认后才执行。
- 输入材料数量不足、金钱不足或物品在确认期间发生变化时，操作失败且不产生部分扣除。

#### 第一步：选择用于兑换的词条

1. 扫描玩家背包内的全部 `st/p#key` 属性石。
2. 非最高级属性石仅在同一物品数量达到 2 块时列入可选项。
3. 最高级 `special` 属性石在数量达到 1 块时列入可选项。
4. 向玩家显示“请选择你要用于兑换的词条：”。
5. 为每种符合数量条件的属性石生成一个按钮，按钮文案使用物品的 `unit_name`；非最高级按需消耗的 2 块显示，最高级按 1 块显示。
6. 若背包内不存在任何符合条件的属性石，提示玩家暂无可兑换词条。

#### 第二步：选择兑换目标类型

1. 玩家选择非最高级属性石后，系统枚举评分类别中高一级的全部词条类型。
2. 玩家选择最高级 `special` 属性石后，系统枚举最低级 `base` 的全部词条类型。
3. 向玩家显示“选择你要兑换的词条类型：”。
4. 玩家从列出的目标词条中主动选择产物，不随机产出。
5. 选择后进入最终确认，确认文案必须包含输入物品及数量、输出物品及数量、黄金费用。

## 8. 实现边界

### 8.1 伤害与成功标记

- 成功标记必须由最终战斗结果写入，不得仅以玩家发起攻击或开始释放绝招作为成功。
- 白虎以实际招架/躲闪结果为准。
- 青龙以玩家本人经过 `do_attack()` 的实际命中结果为准，不要求伤害大于 0。
- 玄武以最终实际伤害大于 0 为准。
- 反震、持续伤害、装备额外伤害和召唤物伤害不能触发青龙标记。
- 玄武标记仅接受玩家本人经过 `do_attack()` 产生且最终大于 0 的伤害。反震、持续伤害、跟随物伤害、装备独立追加伤害和绕过正常攻击流程的伤害均不能写入标记。

### 8.2 异常和并发安全

- 房间心跳只处理房间所有者玩家，不对跟随物、尸体或神兽重复初始化试炼。
- 同一心跳只能使息数增加一次。
- 玩家死亡和房间心跳同时发生时，结束流程必须幂等，不重复调用 `die()`、不重复发奖或更新纪录。
- 神兽气血触底后的回满必须发生在普通 NPC 死亡和战斗结束之前。
- 所有临时回调和标记必须在离开、死亡、掉线清理和资源热更时可安全释放。

## 9. 验收要求

### 9.1 试炼通用验收

- 四个平台均可成功创建对应神兽，不再出现 `resource not preloaded: ...wudao_ss`。
- 每只神兽气血为 1 亿，气血归零后立即回满且战斗继续。
- 神兽不会获得负面状态。
- 第一次心跳后玩家显示绿色 `1息` 状态，5 秒后替换为 `2息`，不显示叠层数。
- 第 `n` 息实际生效 `-n%` 绝招释放时间加成和 `-n%` 疗伤效果。
- 每种试炼首次到达新息数时正确发放对应基础属性石，重复到达不重复发放。
- 离开、死亡和掉线后不留下神兽、试炼状态或成功标记。

### 9.2 分试炼验收

- 白虎：本息成功招架或躲闪则可进入下一息；未成功则心跳时死亡；49 息阈值为 42 万。
- 朱雀：每息一次六连击；49 息为 98% `diff_fy_per2` 与 5000 万总伤害基准；不检查成功标记。
- 青龙：本息至少命中一次则可进入下一息；未命中则心跳时死亡；49 息阈值为 49 万。
- 玄武：本息至少造成一次大于 0 的伤害则可进入下一息；未破免则心跳时死亡；49 息固定免伤为 490 万。

### 9.3 塔主与兑换验收

- 塔顶始终存在一名气血 5600 万的武道塔主。
- 塔主正确显示“四方试炼”和“词条兑换”询问选项。
- 四方试炼说明与实际机制一致。
- 兑换操作仅接受合法的 `st/p#key` 材料，具备二次确认和原子性扣除。
- 第一步仅列出数量达到 2 块的非最高级属性石和数量达到 1 块的最高级属性石。
- 第二步正确列出下一等级词条，或在选择最高级词条时列出基础词条。
- 最高级词条拆分的 100 两黄金费用正确扣除，余额不足时不消耗材料。

## 10. 需求状态

当前功能边界已确认，无剩余待确认项。
