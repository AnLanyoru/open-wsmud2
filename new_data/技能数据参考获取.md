# 技能数据获取指南

通过 `mud-api.cjs` 连接正式服，使用 `checkskill` 命令获取技能数据。

## 1. 启动

```bash
cd new_data
node mud-api.cjs
```

看到以下输出即就绪：

```
进入游戏成功！玩家: 长孙汉 Lv.0
MUD API 已启动
http://localhost:3099
```

## 2. 获取技能数据

### 命令

```
checkskill <技能ID> <等级>
```

等级不能超过5000级否则变为1000级数据
技能 ID 对应项目 `server/res/skill/` 下各 `.ts` 文件中的 `id` 字段。

### 发送

```bash
curl -s -X POST http://localhost:3099/api/cmd \
  -H "Content-Type: application/json" \
  -d '{"cmd":"checkskill <技能ID> <等级>","quietMs":500}'
```

### 返回

数据在 `messages` 数组中，为带 MUD 颜色标签的文本：

```json
{
  "ok": true,
  "cmd": "checkskill taijiquan 100",
  "elapsed": 585,
  "count": 1,
  "messages": [
    "<hiy>太极拳</hiy>\n武当派稀有武技\n\n<blk>当装备为基本拳脚时：\n攻击：+135\n命中：+135\n臂力：+12</blk>\n..."
  ],
  "json": []
}
```

- 技能存在且等级有效 → `messages` 中含技能描述
- 技能不存在 → `messages: ["没有这个技能。"]`
- 可能混入游戏世界其他消息（战斗、聊天），按技能名关键字过滤即可

## 3. 确认技能成长

技能成长指同一技能在不同等级下的属性变化规律。确认方法：对同一技能取多个等级的数据，对比差异。

### 步骤

**拉取多等级数据**。以 100 级为间隔，拉取 100~1000 级 1000级为间隔拉取2000-5000级：

```bash
SKILL="taijiquan"
for lv in 100 200 300 400 500 600 700 800 900 1000 5000; do
  curl -s -X POST http://localhost:3099/api/cmd \
    -H "Content-Type: application/json" \
    -d "{\"cmd\":\"checkskill $SKILL $lv\",\"quietMs\":500}" \
    -o "${SKILL}_${lv}.json"
  sleep 0.3
done
```

**对比关键字段**。从返回文本中提取属性值，观察随等级的变化：

```js
// 以正则从 messages 文本中提取数值
const atk = msg.match(/攻击：\+(\d+)/)?.[1];     // 攻击加成
const def = msg.match(/防御：\+(\d+)/)?.[1];     // 防御加成
const hit = msg.match(/命中：\+(\d+)/)?.[1];     // 命中加成
const dmg = msg.match(/最终伤害：\+(\d+)%/)?.[1]; // 伤害百分比

// 对比相邻等级差值，确认成长曲线（线性/阶梯/非线性）
```

**确认成长类型**。常见规律：

| 类型 | 特征 | 示例 |
|------|------|------|
| 线性 | 每级固定增量，如攻击 +5/级 | 低级技能 |
| 阶梯 | 每 N 级跳一次大数值 | 品阶技能 |
| 衰减 | 低级增长快，高级减慢 | 高级内功 |

### 判断方法

1. 算出相邻等级的属性差值 → 看是否恒定
2. 画出等级-属性曲线 → 看形状
3. 对照 `server/res/skill/<技能>.ts` 源码中 `query_desc` 方法 → 确认计算公式

## 4. 注意事项

- 请求间隔 ≥ 300ms，太快会被限流（返回"不要急，慢慢来"）
- 等级范围 1~4999
- `quietMs` 设 500 即可（技能数据通常是单条响应）
- 技能命名规则：同名技能多品阶版本后缀数字，如 `taijiquan` → `taijiquan2` → `taijiquan3`，ID 来自源码 `id` 字段
- API 重启后自动重新登录，约 3~5 秒恢复
- 拉取的数据要记得清理，不留存
