# 启动脚本

> ⚠️ **注意：本目录下的脚本仅用于首次部署完成后的日常重启维护，不可直接用于首次启动！**

## 何时使用

- 服务器重启后重新拉起服务
- 手动停止服务后再次启动
- 日常维护重启

## 何时不能使用

- ❌ 首次部署 — 请使用 `首次部署/` 下的脚本
- ❌ 更新资源 — 请使用 `打包资源/` 下的脚本

## 使用方法

根据你的服务器平台选择对应目录下的启动脚本：

| 平台    | 脚本                        |
|---------|----------------------------|
| macOS   | `mac/start.sh`             |
| Linux   | `linux/start.sh`           |
| Windows | `windows/start.bat`        |

### 首次部署流程

1. 在开发机上运行 `首次部署/<平台>/打包生成部署包` → 生成 `fast_start.tar`
2. 将 `fast_start.tar` 与同目录下的 `放置在部署包同目录启动自动部署` 复制到服务器
3. 在服务器上运行 `放置在部署包同目录启动自动部署` → 自动解压并启动

### 后续更新流程

1. 在开发机上运行 `打包资源/<平台>/打包生成更新包` → 生成 `release.tar`
2. 将 `release.tar` 与同目录下的 `放置在更新包同目录启动自动更新资源` 复制到服务器
3. 在服务器上运行 `放置在更新包同目录启动自动更新资源` → 自动更新并重启
